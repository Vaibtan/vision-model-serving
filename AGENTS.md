## Agent skills

### Issue tracker

Issues and PRDs are tracked in this repository's GitHub Issues. See `docs/agents/issue-tracker.md`.

### Triage labels

Use the five default canonical triage labels. See `docs/agents/triage-labels.md`.

### Domain docs

This repository uses a single-context domain-doc layout. See `docs/agents/domain.md`.

### Commit and pull request wording

- Do not include ticket or issue identifiers in commit subjects, commit bodies, pull request titles, or pull request descriptions.
- Keep each commit message to one or two lines that state exactly what was implemented, updated, or changed.
- Keep each pull request description slightly more detailed than its commit messages, but no longer than three lines.
