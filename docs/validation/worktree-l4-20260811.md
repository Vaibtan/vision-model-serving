## Issues found during L4 validation and closed

- exact FocalNet patch verification now compares tracked Git tree objects and
  works with read-only repository objects;
- the acceptance contract now permits the reference detector's intentional
  border overhang while verifying positive extents and coordinate consistency;
- the packaged HTTP client polls below the default rate and honors throttling
  `Retry-After` without resubmitting inference;
- job directories/files are owner-writable and validation-group-readable
  (`0750`/`0640`), enabling fail-closed privacy inspection without world access;
- the monitoring frontend reads the actual executor readiness field;
- browser validation imports dependency-free constants rather than the ML
  serving package; and
- native extension build intermediates are removed from the executor runtime
  image and the benchmark Dockerfile identity constant was advanced.
